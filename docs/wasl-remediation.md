# متابعة خطة إصلاح «وصل»

المرجع: تقرير التقييم وخطة الإصلاح بتاريخ 10 أكتوبر 2026. لا تُغلق ملاحظة إلا بدليل: اسم اختبار آلي، أو سجل تشغيل، أو commit، أو لقطة. بوابة كل مرحلة: `npm run verify` ينجح، واختبارات المرحلة تنجح، وهذا الملف محدّث.

## القرارات المعتمدة

| الرمز | القرار |
|---|---|
| D1 | الربط بتسجيل دخول Google عبر OAuth بصلاحية `drive.file` مع Google Picker. الفريق لا يستعرض مجلدات Drive من داخل النظام إطلاقاً، ويصل إلى ملفات مشاريعه عبر مرفقات الفكرة فقط. |
| D2 | مالك النظام root وحده يربط Drive ويفصله. root أو مدير النظام يستعرض المجلدات ويختار مجلد الرفع. |
| D3 | الملفات تُخزَّن في مجلد الأرشفة المعتمد `WaslPlatform`، ويُنشئ النظام داخله مجلدات فرعية حسب التاريخ والشركة والمشروع. |
| D4 | قاعدة البيانات Supabase Postgres. يفعّل يوسف اتصال Supabase في Claude Code. |
| D5 | الواجهة عربية فقط، ويُحذف نظام الترجمة غير الموصول. |
| D6 | التصميم ملك المصمم ويعتمده بنفسه. الأفكار وكتابة المحتوى تحتاج اعتماد الإدارة. |
| D7 | حساب Google المالك لمجلد `WaslPlatform` هو yosfgfx@gmail.com. المساحة المجانية 15 جيجابايت وقد يلزم Google One للفيديو. |
| D8 | ترتيب الأرشيف: `WaslPlatform/السنة/الشهر - أعمال الشهر/أعمال الشركة/الكود · نوع العمل · العنوان/` وبداخله `01 الموجز والمحتوى` و`02 عروض الأسعار` و`03 التصاميم النهائية` و`ملخص المشروع.pdf`. |
| D9 | الشهر هو شهر التسليم. ملفات المشروع أثناء العمل في `WaslPlatform/قيد التنفيذ/`، ويُنقل المجلد عند التسليم إلى شهر التسليم. |
| D10 | البريد يُرسل من y.abdulrahman@hayen-hr.com عبر SMTP في Microsoft 365 (`smtp.office365.com:587`) بكلمة مرور تطبيق يضعها يوسف بنفسه في `.env.local`. سجل SPF للنطاق يسمح بالإرسال من Microsoft. |

| D11 | النشر على Netlify بعنوان `https://wusl.netlify.app`. أُضيف العنوان في Google Cloud إلى العناوين المسموحة، وعنوان الرجوع، ومفتاح Picker، والنطاقات المعتمدة. على Netlify: `MEDIA_APP_ORIGIN=https://wusl.netlify.app`، والاتصال بقاعدة البيانات عبر منفذ المعاملات 6543، والملفات المؤقتة في Supabase Storage. |
أثر القرار D6: الملاحظة H2 لم تعد خللاً. المطلوب بدلها توضيح المرحلة في الواجهة (مراجعة المصمم النهائية) وإبقاء تعليقات صاحب الفكرة دون أن تمنع التسليم.
