# الوصول البرمجي وخادم MCP في «وصل»

## من يراه ومن يستخدمه

- مديرو النظام فقط افتراضياً. يظهر لهم تبويب «API وMCP» في «إدارة النظام».
- يستطيع مدير النظام إتاحته للفريق كله من التبويب نفسه. عندها يظهر قسم «الوصول البرمجي وMCP» في «حسابي» لكل عضو، ويعمل كل عضو بصلاحيات دوره فقط.
- عند إعادته لمديري النظام فقط تُلغى فوراً مفاتيح بقية الفريق وتطبيقاتهم المربوطة.
- إنشاء مفتاح أو الموافقة على ربط تطبيق يتطلبان رمزاً جديداً من تطبيق المصادقة، فالتحقق بخطوتين شرط.

## خادم MCP

العنوان: `https://wusl.netlify.app/api/mcp` (Streamable HTTP، بلا جلسات، مناسب لـ Netlify).

| التطبيق | طريقة الربط |
|---|---|
| Claude على الجوال والويب والحاسب | الإعدادات ← Connectors ← Add custom connector، ثم الصق العنوان ← Connect ← سجّل الدخول في صفحة وصل ووافق برمز التحقق |
| Claude Code | `claude mcp add --transport http wasl https://wusl.netlify.app/api/mcp` ثم `/mcp` واختر wasl لتسجيل الدخول |
| ChatGPT (Developer mode) وCursor وغيرها | العنوان نفسه مع OAuth، أو مفتاح في `Authorization: Bearer wasl_…` |

الأدوات (34): نظرة عامة، وبحث الأفكار وتفاصيلها، وإنشاء وتعديل، وإرسال وسحب، واعتماد ورفض وإعادة للتعديل، وجدولة، ومراحل التصميم، وتعليقات، وعروض أسعار، ورفع ملفات (حتى 3 ميجابايت مباشرة أو 100 ميجابايت من رابط https عام) وقراءتها، وإعادة إسناد وإلغاء وإعادة فتح وحذف (بتأكيد صريح)، وإشعارات، والفريق والحسابات، والشركات والتصنيفات والإعدادات، وحالة الأرشيف وإجراءاته، والمهام الدورية، واستيراد الأفكار، والتقرير الشهري. ومعها مورد `wasl://idea/{ideaId}` وقالبا أوامر: «ملخص أسبوعي» و«ملف اعتماد فكرة».

## واجهة REST

كل واجهات النظام الحالية تقبل `Authorization: Bearer wasl_…`، مثل `GET /api/media` و`POST /api/ops` و`GET /api/ideas/{id}`. المفتاح لا يتجاوز صلاحيات صاحبه، وإدارة المفاتيح نفسها لا تتم بمفتاح، من داخل النظام فقط.

## الأمان

- المفاتيح ورموز OAuth تُحفظ بصمتها SHA-256 فقط، وتظهر مرة واحدة عند إنشائها.
- مدة المفتاح 30 أو 90 أو 365 يوماً. رمز OAuth ساعة واحدة، ويتجدد برمز تحديث مدته 30 يوماً يتغير مع كل تجديد، وإعادة استخدام رمز قديم تلغي الربط كله.
- OAuth 2.1 مع PKCE (S256) وتسجيل تلقائي للتطبيقات (RFC 7591) واكتشاف (RFC 8414 وRFC 9728).
- حد 240 طلباً في الدقيقة لكل مفتاح، وسجل استخدام لكل طلب وأداة يُحفظ 180 يوماً.
- جلب الملفات من رابط يقبل https العام فقط، ويرفض العناوين الداخلية في كل تحويل.
